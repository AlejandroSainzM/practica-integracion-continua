# practica-integracion-continua
Práctica de Integración Continua (CI) utilizando GitHub Actions.

## Verificación de Integración Continua

Este repositorio utiliza GitHub Actions para ejecutar
automáticamente un proceso de integración continua
cada vez que se realizan cambios en la rama main.

Esta modificación permitirá comprobar que un nuevo
commit activa nuevamente el Workflow configurado.
